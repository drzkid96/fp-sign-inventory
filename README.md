# FP Sign Inventory

Street-level sign inventory on an aerial base: sign code and sign picture at each location, with 11x17 PDF and Excel exports.

Static site on GitHub Pages. No server, no paid services.

| Folder | Contents |
|---|---|
| `js/` | Map, data pull, code matching, exports |
| `css/` | Screen and 11x17 print styles |
| `data/` | Code-match table, sign sprites, verified area files |

Status: repository set up, build pending approval.
